# 🛢️ Нефтекод 2026: Автономный комплекс MES/APC Евро-5 (Архитектура v3)

Автономная мультиагентная система управления технологическим процессом производства дизельного топлива ГОСТ 32511-2013 (Евро-5, сера <= 10 мг/кг) в сквозной цепочке:
**ЭЛОУ-АВТ-6 -> Гидроочистка 24-2000 -> Инлайн-блендинг в товарные резервуары**.

Архитектура v3 построена на принципах **децентрализованных двусторонних переговоров** (ADR-13), независимого **Ядра Безопасности** (SafetyKernel, ADR-24), физического цифрового двойника высокой верности (`PlantSimulator` v2) и асинхронного **ИИ-Супервизора** на базе локальной LLM Qwen 2.5 32B / 27B с детерминированным реплеем на кассетах (`REPLAY_STRICT`).

---

## 🌟 Ключевые возможности и инженерные достижения

1. **Абсолютный приоритет безопасности (ПАЗ/ESD > Качество ГОСТ > Экономика)**:
   - Полная изоляция критических барьеров ярусов T0–T3 (29 технологических ограничений с официальным провенансом).
   - 0 допущений нарушений ПАЗ по физической правде установки (`PlantSimulator.truth()`).
   - Истинное соблюдение температуры вспышки ГОСТ (Flash - 2σ >= 55.0 °C, устранение дефекта E10).
2. **Децентрализованные двусторонние переговоры (Bilateral Negotiation)**:
   - Агенты Оптимизации, Надежности, Качества и Снабжения взаимодействуют через совместный квадратичный ремонт (QP Repair, ADR-21) и вычисление Парето-фронта.
   - Устранение «заморозки в нарушении»: при выходе за огибающую оборудования вырабатывается монотонная траектория восстановления (`RECOVERY_ADVISORY`, инвариант I4/I5).
3. **Отказоустойчивость КИПиА и LIMS (DataGuard v2 + Kalman)**:
   - Фильтрация аппаратного клампинга, выявление залипания анализаторов <= 6 тактов.
   - Непрерывный учет старения калибровки LIMS (σ_calib^2(t) = σ_LIMS^2 + q_drift * Δt).
   - Регламентный переход в `REFUSAL_DATA` при одновременном отказе ПАК и устаревании анализа > 24 ч.
4. **Асинхронный ИИ-Супервизор (LLM Supervisor)**:
   - Интеллектуальный анализ трасс решений, генерация сменных брифингов (`ShiftBriefing`) и ответов оператору (`OperatorAnswer`).
   - 100% заземление на факты (`GroundingChecker` с нулевыми галлюцинациями).
   - Двухфакторный валидатор безопасности (`PolicyValidator`): любая попытка ослабления коэффициентов α блокируется.
   - Поддержка локальных LLM через OpenAI-совместимый эндпоинт (vLLM / Ollama) и 100% автономный CI на кассетах.

## 🚀 Быстрый старт

### 1. Демонстрационный скрипт (5 историй ТЗ §6)
Запуск интерактивной консольной демонстрации ключевых сценариев:
```bash
python scripts/demo_v3.py
# или в интерактивном режиме с паузами:
python scripts/demo_v3.py --interactive
```

### 2. Сквозной реплей сценариев S1–S8 и сводка KPI §15
```bash
python scripts/replay_scenarios.py
```
Скрипт выполняет прогон всех 8 сценариев ТЗ на динамическом стенде `PlantSimulator` v2, сохраняет `data/processed/final_kpis.json` и печатает сравнительную таблицу KPI «до и после модернизации».

### 3. Запуск пульта оператора (веб-консоль на FastAPI)
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
Пульт открывается на `http://localhost:8000/console/` и включает вкладки:
- 📊 **Обзор**: телеметрия комплекса, прогноз, рекомендация МАС;
- 🎛️ **Ручное управление**: песочница «что если» по всем уставкам;
- 🤖 **Агенты и XAI**: полный лог переговоров и вердикт ядра безопасности;
- 🛡️ **Парето-анализ**: многокритериальный фронт допустимых кандидатов;
- 📋 **Журнал смены**: сдача смены и сводки.

Единственный веб-интерфейс проекта — Streamlit-консоль (`src/ui/app.py`) удалена, её функции перенесены в пульт (см. `agents/console_tz/`).

### 4. REST API микросервис (FastAPI)
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
Документация Swagger UI: `http://localhost:8000/docs`.

### 5. Запуск полного набора автоматических тестов
```bash
pytest -v tests/
```
Включает 218+ тестов: юнит-тесты модулей, тесты свойств (Hypothesis), регрессии аудита E1–E12, тесты архитектурной изоляции AST, задержка такта p95 <= 2.0 с и LLM-оценка на кассетах.

## 🤖 Развертывание локальной LLM (Qwen 2.5 32B / 27B)

Система поддерживает работу с открытыми моделями семейства Qwen без обращения к внешним облачным сервисам:

### Вариант 1: vLLM (рекомендуется для продакшн / GPU)
```bash
vllm serve Qwen/Qwen2.5-32B-Instruct \
  --host 0.0.0.0 --port 8000 \
  --tensor-parallel-size 1 \
  --max-model-len 4096
```

### Вариант 2: Ollama (для локальной разработки)
```bash
ollama run qwen2.5:32b
```

### Настройка подключения в МАС
Задайте переменные окружения:
```bash
export NEFTEKOD_LLM_MODE="LIVE"                  # LIVE или REPLAY_STRICT
export NEFTEKOD_LLM_BASE_URL="http://localhost:8000/v1"
export NEFTEKOD_LLM_API_KEY="none"
export NEFTEKOD_LLM_MODEL="Qwen/Qwen2.5-32B-Instruct"
```
Для автономной работы без LLM-бэкенда используется режим `REPLAY_STRICT` (по умолчанию), воспроизводящий эталонные ответы из `data/llm_cassettes/demo/`.
