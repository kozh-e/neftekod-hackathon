# Макет пульта — эталон для сверки

Три экрана 1920×1080 из Design-холста «Пульт оператора Р-202». Это **визуальная спецификация** для R4 и R5 (и сверки R0/R6).

| Экран | Эталон вёрстки (открыть в браузере) | Скриншот | Фикстура API |
|---|---|---|---|
| Совет: оператор правит рекомендацию (S2) | `01_advisory_edit.html` | `01_advisory_edit.png` | `advisory.json` |
| Автомат: выход на оптимум (S1) | `02_auto.html` | `02_auto.png` | `auto.json` |
| Автомат отключён: нет данных (S3d) | `03_refusal_no_data.html` | `03_refusal_no_data.png` | `refusal.json` |

## Как пользоваться
- **HTML — главный эталон.** Открой файл в Chrome (работает локально, без сервера), инспектором смотри точные цвета, размеры,
  отступы, тексты. Все стили — inline, токены совпадают с `ROLE_4_frontend_shell.md §1`.
- **PNG — для быстрой сверки глазами.** Сравнивай свой скриншот `http://localhost:8000/console/?fixture=<name>` на 1920×1080 с PNG.
- **Что копировать:** компоновку, иерархию, цвета, размеры шрифтов, тексты подписей и кнопок, порядок слоёв на графиках.
- **Что НЕ копировать:** числа (9.2 ppm, 12 %, 1.24 млн ₽/ч, траектории) — они иллюстративные, в реальном пульте всё из API.
  Графики в макете нарисованы SVG вручную — в реализации это ECharts (R5), выглядеть должно так же.
- В макете поля ввода и кнопки статичны; поведение описано в файлах ролей, а не в макете.

## Источник и пересборка
- `canvas_source/` — исходники холста (`*.dc.html` + `canvas.json`), формат редактора Design. Не открываются напрямую в браузере.
- Автономные HTML собираются скриптом: `python agents/console_tz/mockups/_build.py agents/console_tz/mockups/canvas_source`
- Скриншоты: `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --hide-scrollbars --window-size=1920,1080 --virtual-time-budget=5000 --screenshot=<out.png> file://<abs path to html>`
- Если холст правится — пересобрать HTML и PNG, закоммитить вместе.
