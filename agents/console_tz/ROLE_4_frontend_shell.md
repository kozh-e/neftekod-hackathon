# R4. Фронтенд: каркас пульта, карточка решения, режимы

Ты верстаешь весь экран пульта, **кроме внутренностей графиков** (их рисует R5 через `charts.js`). Прочитай `README.md`,
`01_CONTRACT.md`, `ROLE_5_frontend_charts.md` §«API модуля» (как вызывать графики). Бэкенд не нужен: работай от фикстур
`static/console/fixtures/{advisory,auto,refusal,preview_ok,preview_blocked}.json`.

## Файлы
`static/console/index.html`, `static/console/styles.css`, `static/console/app.js`, `static/console/api.js`.
Чистый HTML/CSS/JS (ES-модули, `<script type="module">`), **без** npm, фреймворков, CDN (кроме того, что R5 положил в `vendor/`).
Шрифты: IBM Plex Sans + IBM Plex Mono — подключи через Google Fonts **с фолбэком** `system-ui` / `ui-monospace` (на площадке может не быть интернета).

## 1. Дизайн-токены (`styles.css`, `:root`) — использовать только их
```

--ink: #16181A;        --ink-2: #3F4448;      --ink-3: #4A4E53;     --ink-muted: #5A5F64;
--fact: #2B2F33;       --hold: #7D8288;       --rec: #1D5AA6;       --edit: #B45309;  --edit-ink: #8A3F06;
--limit: #B3261E;      --risk-bg: #FBE9E7;    --risk-ink: #7A1712;
--auto: #17784F;       --ok-bg: #E1EFE8;      --ok-ink: #0F5A3A;
--warn-frame: #C98A1B; --warn-fill: #8A5A0B;  --warn-bg: #FFF1C2;    --warn-ink: #4A3004;  --warn-btn: #6B4506;

Правило ISA-101: цвет только у отклонений, режима и траекторий. Никаких градиентов, теней, эмодзи. Иконки — inline SVG, stroke.
Тёмной темы нет (проектор). Минимальные размеры: значения ≥ 20px, подписи ≥ 13px, кликабельное ≥ 44px по высоте.

```

- Масштабирование: корневой контейнер 1920×1080; если окно меньше — `transform: scale()` по меньшей стороне (letterbox), без перекомпоновки.
- Заголовок каждой CV-панели: `TITLE` (16px, 700, letter-spacing .05em) · тег (mono 14px) · значение (mono 30px) · единица · chip · справа `note`.
- MV-карточка: название + тег; значение (mono 22px); справа «→ 364.5» (цвет траектории) или «заморожено»; мини-график (R5);
  подпись коридора: `шаг ≤ {max_step} {unit}/такт · T0 {lo}–{hi}` или `шаг [из паспорта]`. Рамка 2px цвета траектории, если MV меняется.

## 3. Состояние и поток данных (`app.js`)
- Единый `store = { state, activeKind, choice, edits: {sp: value}, preview, pending }`. Рендер — функция `render(store)`,
  идемпотентная; DOM создаётся один раз, дальше обновляются текст/атрибуты (без `innerHTML` на каждый тик — мигание).
- `api.js`: `getState()`, `preview(u_target)`, `commit(req)`, `reject()`, `setMode()`, `skip()`, `ack(id)`, `ask(q)`, `shiftReport()`,
  `demo.*`. Режим `?fixture=advisory|auto|refusal` → все чтения из фикстур, `preview` отдаёт `preview_ok`, а если T6 шаг > 3 — `preview_blocked`.
- Опрос `GET /state` каждые 2 с (и сразу после любого POST). Если `recommendation.cycle_id` сменился, а у оператора есть правки —
  **не затирать** правки молча: показать полосу «Система обновила рекомендацию · [Показать новую] [Оставить мои]».
- Какая траектория активна на графиках (передаётся в R5):
  - есть `edits` и получен `preview` → `operator` (оранжевая), `recommendation` → тонкий контур;
  - иначе выбран `choice` ≠ balanced → соответствующая `alternative` (синяя);
  - иначе `recommendation` (синяя); в AUTO — план (`auto.next_step`/`plan` → синяя «план автомата»);
  - `hold` рисуется всегда (серый пунктир), кроме отказа по данным без прогноза.

## 4. Правая колонка по состояниям

### 4.1 СОВЕТ, есть рекомендация (`status` ∈ SUCCESS*, RECOVERY_ADVISORY)
Карточка (`--card`, рамка 2px `--rec`):
1. Шапка: «СИСТЕМА ПРЕДЛАГАЕТ» (18px, 700, `--rec`) · справа «{created_at HH:MM} · актуально до {valid_until HH:MM}».
2. `narrative` (18px, line-height 1.4).
3. Строка на каждое `change`: `<label>` название + тег · текущее (mono) · стрелка · `<input inputmode="decimal">` с target (mono 22px) · пояснение.
   Если значение отличается от рекомендации: фон строки `#FFF4EA`, рамка поля `--edit`, текст «изменено вами / рекомендация X».
   Колесо мыши и ↑/↓ меняют значение на 0.1 шага коридора. Ввод → debounce 250 мс → `preview`.
4. Строка ядра (иконка щита): `preview.kernel` или `recommendation.kernel` → «проверено ядром T0–T3: нарушений нет · шаг в коридоре»
   зелёным (`--auto`) либо красным текст первой непройденной проверки/`blocking_reason`. Для `kernel.limited` — «Ядро ограничило T6: +3.5 → +1.7».
5. Бейдж риска (только если `risk.probability ≥ 0.05` у активной траектории): `--risk-bg`, рамка `--limit`,
   «Риск превышения {limit} {unit}: {p}% через {ч} ч {мм} мин · при рекомендации: {p_rec}%».
6. Три плитки эффекта: «Сера через 4 ч», «Запас по вспышке», «Маржа» — значения активной траектории + мелко рек./без изм.
7. Сегмент «Макс. маржа | Сбалансировано | Макс. запас» (`aria-pressed`); недоступные — disabled с title-причиной.
8. Кнопки: главная во всю ширину, 56px, `--ink` фон: «Отправить» / «Отправить мои значения» (если есть правки) — **disabled при
   `can_commit=false`**, под ней причина. Ниже в ряд: «Вернуть рекомендацию» (только если есть правки) и «Отклонить».
   Отправка: подтверждение **внутри кнопки** (текст → «Подтвердить: T6 364.5, GOR 380», второй клик в течение 5 с), без модалок.
9. Кнопка-раскрывашка «Почему так решили: N агентов, M возражений» → список `agents` (агент, stance-иконка, текст).

### 4.2 СОВЕТ, `NO_CHANGE_DEADBAND`
Компактная карточка: «Изменения не требуются» + narrative + эффект «без изменений». Кнопок отправки нет.

### 4.3 Отказ (`status` ∈ REFUSAL_*)
Жёлтый блок (`--warn-bg`, рамка 2px `--warn-frame`): иконка ⊘ + «НЕТ РЕКОМЕНДАЦИИ», `refusal.text`, «ЧТО ПРОВЕРИТЬ» — чекбоксы
(`<input type=checkbox>` + `<label>`, локальное состояние, сохранять в `localStorage` по `cycle_id` в try/catch),
блок «Автомат снова станет доступен, когда …» (`auto_resume_condition`), кнопка «Заказать анализ LIMS» (пока — запись в ленту через `ask`/заглушку).
**Кнопок «Отправить»/«Отклонить» нет в DOM** (не disabled — отсутствуют). MV-подпись «все уставки заморожены (safe-hold)» с замком.

### 4.4 АВТОМАТ
Карточка (рамка 2px `--auto`): «СЛЕДУЮЩИЙ ШАГ АВТОМАТА» · справа «через» + таймер `mm:ss` (mono 34px, локальный отсчёт от `next_step.in_s`,
синхронизация с каждым опросом) · прогресс-бар · строка изменения (как в 4.1, но без поля ввода, target синим) · `narrative` ·
кнопки «Пропустить этот шаг» (контур) и «Взять управление» (`--ink`). Ниже панель «КОРИДОР АВТОМАТА · из паспорта · только просмотр»:
таблица MV × (макс. шаг, диапазон T0); `null` → «[из паспорта]».

## 5. Статус-бар, баннер, тревоги, режим
- Кнопка режима: в СОВЕТЕ — «Включить автомат» (контур `--auto`); если `auto_available=false` — пунктирная disabled «Автомат недоступен»
  с `title=auto_unavailable_reason`. В АВТОМАТЕ — «Взять управление» + «в автомате N мин».
- Включение автомата — подтверждение внутри кнопки (как «Отправить»). 409 → тост с `detail.text`.
- Тревоги: счётчик в статус-баре; если есть неквитированная T0/T1 — плашка под статус-баром (`--risk-bg`, рамка `--limit`, 56px):
  «T1 · {text} · {value} / {limit}» + [Квитировать]. Несколько — показывать первую + «ещё N».
- Баннер автовыхода — §2; [Квитировать] → `ack(banner.id)`.
- Часы — `clock.now` в формате HH:MM (модельное время).
- «Сдать смену» → правая панель-оверлей поверх правой колонки с `shiftReport().markdown` (минимальный рендер markdown: заголовки, списки, жирный) и [Закрыть].
- «Спросить систему» → ответ в такой же панели-оверлее; пока ждём — «Система думает…», таймаут 25 с.

## 6. Панель ведущего `?demo=1`
Маленькая плавающая панель в левом нижнем углу, сворачивается кнопкой «свернуть» (глобальные горячие клавиши не использовать):
кнопки сценариев S1/S2/S3d/S4/S5, скорость (пауза, 2 с, 5 с, 10 с), «+1 такт», «Отказ ПАК серы» (`fault HT_Q21 nan` + `lims_age 26`),
«Снять отказы». Не должна перекрывать карточку решения.

## 7. Доступность
Все интерактивные элементы — настоящие `<button>`, `<input>`, `<label for>`. Иконки-кнопки с `aria-label`. Лента — `role="log" aria-live="polite"`.
Баннер и тревоги — `role="alert"`. Контраст текста ≥ 4.5:1 (токены выше подобраны под это — не осветлять).

## Приёмка
- `?fixture=advisory|auto|refusal` на 1920×1080 визуально соответствует макету (3 скриншота в `agents/console_tz/STATUS.md` или описание сверки).
- В `refusal` нет элементов с текстом «Отправить» (`document.querySelectorAll` проверка в тесте R6).
- Правка T6 до значения с шагом > 3 → кнопка disabled, причина видна; возврат → активна.
- 0 ошибок/предупреждений в консоли браузера; опрос не создаёт утечек (10 минут работы — число DOM-узлов стабильно).
