# ТЗ: Пульт старшего оператора Р-202 (Operator Console v1)

Техническое задание для многоагентной разработки. Исполнители — агенты-программисты
(Gemini 3.8 Flash, режим high). Каждый агент получает **этот README + файл своей роли + `01_CONTRACT.md`**.

Визуальная спецификация: **`agents/console_tz/mockups/`** — 3 экрана 1920×1080 как автономный HTML (эталон: открыть
в браузере, смотреть инспектором) + PNG для сверки глазами. Правила использования — `mockups/README.md`.
Текстовое описание макета — в `ROLE_4_frontend_shell.md`. Числа на макете иллюстративные.

---

## 1. Зачем

Текущий UI (`src/ui/app.py`, Streamlit) показывает «как устроена система», а не «что делать оператору».
Нужен отдельный пульт на один экран (проектор, жюри хакатона + реальный старший оператор), который отвечает на 4 вопроса:

1. Что происходит сейчас и куда процесс уйдёт **без вмешательства**?
2. Что **предлагает система** и зачем?
3. **Что будет, если применить** — рекомендацию, альтернативу или **мою правку**?
4. Кто сейчас управляет — **Совет** (оператор подтверждает) или **Автомат** (система сама)?

## 2. Зафиксированные продуктовые решения (не пересматривать)

| D2 | Два режима: **СОВЕТ** (оператор может изменить предложенные значения, затем «Отправить») и **АВТОМАТ** (система применяет сама). Переключение одной кнопкой. |
| D3 | Любая правка оператора → мгновенный пересчёт прогноза + проверка ядром безопасности T0–T3 + проверка коридора шага. |

## 5. Общие правила для всех агентов (обязательны)

1. **Не выдумывать числа.** Лимиты, шаги, σ, пороги — только из кода (`src/agents/registry.py`, `src/agents/estimation.py`,
   `src/agents/policy.py`, `src/agents/limits.py`, `src/twin/params.py`) или из `agents/DOMAIN_KNOWLEDGE.md`.
   Нет источника → значение `null` в API и `[из паспорта]` в UI + строка в `agents/console_tz/QUESTIONS.md`. Остановиться на этом месте, не угадывать.
2. **Числа в макете иллюстративные.** Не хардкодить 9.3 ppm, 12 %, 1.24 млн ₽/ч и т. п. Всё отображаемое берётся из API.
3. **Безопасность выше всего.** Никакой путь (commit, автомат, демо) не применяет уставку, не прошедшую `SafetyKernel.verify` и проверку коридора. Отказ ядра = HTTP 409 с причиной, а не «тихий» пропуск.
4. **Стиль кода** как в репозитории: Python 3.12, pydantic v2 (`Frozen`-модели из `src/agents/contracts.py` — образец), docstring и комментарии **на русском**, типы везде. JS — ES2020 модули без сборки, без фреймворков.
5. **Маленькие шаги.** После каждого логического куска — запуск своих тестов. Не делать массовых рефакторингов.
6. **Перед завершением** роль отчитывается в `agents/console_tz/STATUS.md`: что сделано, какие тесты зелёные (команда + вывод последних строк), что осталось, какие допущения.
7. Команды проверки: `pytest -q tests/console` (свои) и `pytest -q` (регресс, не должен сломаться).
   Запуск: `uvicorn main:app --port 8000` → пульт на `http://localhost:8000/console/`.

## 6. Термины

- **SP-имена MV** (ключи `delta_u`/`u_target`): `HT_FEED_SP`, `HT_TIN_SP`, `HT_P_SP`, `HT_GOR_SP`, `AVT_T55_SP`.
  Соответствие тегам PV — `MV_TAG_MAP` в `src/agents/estimation.py:56` (`HT_F9`, `HT_T6`, `HT_P13`, `HT_GOR`, `AVT_T55`).
- **CV**: `sulfur` (выход двойника `HT_S_PRODUCT`, онлайн-тег `HT_Q21`, лимит ≤ 10 ppm), `flash` (`HT_FLASH`, ≥ 55 °C),
  `dp` (`HT_DP_KPA`, тег `HT_P8`, T1 ≤ 454.5 кПа).
- **Такт** = 10 мин модельного времени (`FullChainTwin.dt_min`).
- **Статусы решения** — `DecisionStatus` в `src/agents/contracts.py:301`.
