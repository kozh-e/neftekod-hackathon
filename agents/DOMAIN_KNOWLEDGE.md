# DOMAIN_KNOWLEDGE

Инженерный справочник технологических параметров, ограничений и математических моделей для AI-ассистентов проекта «Нефтекод».
Содержит явное разграничение между обязательными регламентными требованиями [Норматив ТЗ / ПАЗ] и принятыми расчетными гипотезами [Инженерное допущение].

## 1. Технологические границы оборудования и ПАЗ/ESD (ReliabilityAgent)

Обязательный 5% защитный буфер отсечения кандидатов управляющих воздействий (Hard-Veto Gate):

- T55 (перевал змеевика атмосферно-вакуумной печи П-3 / COT):
  - [Норматив ТЗ / ПАЗ] Рабочий диапазон регламента: 375.0 - 385.0 °C.
  - [Норматив ТЗ / ПАЗ] Верхний технологический предел: 387.0 °C (интенсивный крекинг и закоксовывание змеевика).
  - [Норматив ТЗ / ПАЗ] Аварийная уставка ПАЗ (отсечка топлива): 395.0 °C.
  - [Инженерное допущение] 5% защитный буфер безопасности: T55 <= 386.40 °C.
  - [Инженерное допущение] Зона предупреждения: [380.0, 386.40) °C.
  - [Инженерное допущение] Логарифмический штраф риска: Penalty = -mu * ln((386.40 - T55) / 12.0), где mu = 1000.0 руб/ч.

- F31 (общий расход сырья/мазута в змеевики печи П-3):
  - [Норматив ТЗ / ПАЗ] Аварийный минимум от прогара труб: не менее 350.0 м3/ч.
  - [Инженерное допущение] 5% защитный буфер безопасности: F31 >= 362.50 м3/ч.

- W10 (перепад давления на слое катализатора реактора гидроочистки Р-202):
  - [Норматив ТЗ / ПАЗ] Рабочий диапазон слоя: 1.5 - 3.5 кгс/см2.
  - [Норматив ТЗ / ПАЗ] Предельный рабочий перепад в цикле: 4.80 кгс/см2.
  - [Норматив ТЗ / ПАЗ] Аварийная блокировка ПАЗ (остановка сырьевых насосов): >= 5.50 кгс/см2 (разрушение колосников и катализатора).
  - [Инженерное допущение] 5% защитный буфер безопасности: W10 <= 4.635 кгс/см2.

- Температурный режим реакторов Р-201/202 (секция 24-2000):
  - [Норматив ТЗ / ПАЗ] Температура газосырьевой смеси на входе (T5, T11): 340.0 - 375.0 °C.
  - [Норматив ТЗ / ПАЗ] Максимальная температура реакционного слоя: не выше 390.0 °C.
  - [Норматив ТЗ / ПАЗ] Градиент экзотермы по слою: Delta_T <= 25.0 °C. При превышении — принудительное увеличение водородного квенча F15.
  - [Норматив ТЗ / ПАЗ] Кратность циркуляции ВСГ (F2) к сырью: строго не менее 300 нм3 ВСГ / м3 сырья (защита катализатора от зауглероживания).

- P52 (перепад давления над 4-й насадкой вакуумной колонны К-10):
  - [Норматив ТЗ / ПАЗ] Предельный рабочий перепад (риск захлебывания колонны): не более 0.080 кгс/см2.
  - [Инженерное допущение] 5% защитный буфер безопасности: P52 <= 0.077 кгс/см2.

- P50, P51 (глубина вакуума в шлеме колонны К-10):
  - [Норматив ТЗ / ПАЗ] Остаточное давление: 40.0 - 60.0 мм рт. ст. (0.05 - 0.08 кгс/см2 абс.).
  - [Норматив ТЗ / ПАЗ] Предел безопасной работы: остаточное давление верха К-10 не хуже 65.0 мм рт. ст.
  - [Норматив ТЗ / ПАЗ] Деградация режима: при росте остаточного давления > 75.0 мм рт. ст. обязательно снижение тепловой нагрузки печи для предотвращения осмоления насадки.

- L43 (уровень гудрона в кубе колонны К-10):
  - [Норматив ТЗ / ПАЗ] Нормальный рабочий диапазон: 45.0% - 70.0%.
  - [Норматив ТЗ / ПАЗ] Нижняя блокировка ПАЗ: L43 <= 25.0% (опасность срыва подачи насосов откачки Н-34 и осушения куба).
  - [Норматив ТЗ / ПАЗ] Верхняя блокировка ПАЗ: L43 >= 80.0% (опасность заброса тяжелого гудрона в дистилляты).

- F45 (циркуляционный холодный квенч куба К-10):
  - [Норматив ТЗ / ПАЗ] Расход квенча не менее 12.0 м3/ч для удержания температуры куба T48 <= 360.0 °C и предотвращения поликонденсации смол.

- Колонна К-2 (атмосферный блок):
  - [Норматив ТЗ / ПАЗ] Давление верха (P21, P22, P23, P67): не более 1.6 кгс/см2 (сброс предохранительных клапанов на факел).
  - [Норматив ТЗ / ПАЗ] Температура куба (T33): не более 348.0 °C (во избежание вторичного крекинга).

## 2. Нормативы качества ГОСТ 32511-2013 Евро-5 (QualityAgent)

- Сера (Sulfur):
  - [Норматив ТЗ / ПАЗ] Норматив ГОСТ Евро-5: <= 10.0 мг/кг (ppm).
  - [Инженерное допущение] 5% буфер качества: сера гидрогенизата <= 9.50 ppm.

- Плотность при 15 °C (Density):
  - [Норматив ТЗ / ПАЗ] Норматив ГОСТ: от 820.0 до 845.0 кг/м3.
  - [Инженерное допущение] 5% буфер качества: [821.25, 843.75] кг/м3.

- Температура вспышки в закрытом тигле (Flash Point):
  - [Норматив ТЗ / ПАЗ] Летнее и межсезонное дизельное топливо: не ниже 55.0 °C.
  - [Норматив ТЗ / ПАЗ] Зимнее дизельное топливо: не ниже 30.0 °C.
  - [Инженерное допущение] Целевая уставка блендинга летнего/межсезонного ДТ с буфером 1.0 °C: Flash >= 56.0 °C.

- Предельная температура фильтруемости (CFPP / ПТФ):
  - [Норматив ТЗ / ПАЗ] Сорт C (летнее): target_cfpp <= -5.0 °C.
  - [Норматив ТЗ / ПАЗ] Сорт E (межсезонное): target_cfpp <= -15.0 °C.
  - [Норматив ТЗ / ПАЗ] Сорт F (межсезонное): target_cfpp <= -20.0 °C.
  - [Норматив ТЗ / ПАЗ] Зимний класс 1: target_cfpp <= -26.0 °C.

## 3. Математика поточного инлайн-блендинга (Blending Optimizer)

- [Норматив ТЗ / ПАЗ] Стопроцентный материальный баланс смеси:
  sum(v_i) == 100.0% (1.0000).
  Любое решение с небалансом (например, 99.2% или 101.5%) является фатальной ошибкой и бракуется верификатором.

- Компоненты смеси:
  - [Инженерное допущение] Дизельный гидрогенизат: доля >= 50% объема, цена 60 000 руб/т.
  - [Инженерное допущение] Керосиновая фракция ТС-1: доля <= 20% объема, цена 85 000 руб/т, сера 2.0 ppm, CFPP -45.0 °C, Flash 38.0 °C.
  - [Инженерное допущение] Депрессорно-диспергирующая присадка (ДДП): дозировка <= 1500 ppm, цена 1 500 000 руб/т.

- Расчет температуры вспышки смеси (Индекс Вики-Читтендена / Wickey-Chittenden FBI):
  - [Инженерное допущение] Формула индекса компонента: FBI(T) = 10^(a - b * T), где a = 4.1485, b = 0.0601 (калибровано под нефть Urals, требует адаптации под сырьевой пул завода по архивам LIMS).
  - [Инженерное допущение] Объемная аддитивность: FBI_blend = sum(v_i * FBI_i).
  - [Инженерное допущение] Расчетная вспышка смеси: Flash_blend = (a - log10(FBI_blend)) / b.

- Расчет снижения ПТФ присадкой (Изотерма насыщения Ленгмюра для ДДП):
  - [Инженерное допущение] Delta_CFPP(c_ddp) = (Delta_max * c_ddp) / (K_langmuir + c_ddp).
  - [Инженерное допущение] Предельная глубина депрессии: Delta_max = 9.76 °C при c_ddp = 1500 ppm (дальнейший ввод присадки неэффективен).

- [Норматив ТЗ / ПАЗ] Защита от фальсификации (Anti-Dilution Loophole Rule):
  - Строгий запрет на отмывку некондиционного гидрогенизата: если сера дизеля на входе > 10.0 ppm, блендинг немедленно блокируется, даже если за счет добавления керосина итоговая сера смеси была бы < 10.0 ppm.

## 4. Валидация данных КИПиА и регламент Safe Hold (Data Guard)

- [Норматив ТЗ / ПАЗ] Аппаратный клампинг датчиков:
  - Фиксация аппаратных значений шкалы 307.0 и 313.0 (характерно для плотномера D10 и датчиков КИП). При клампинге датчик бракуется.
- [Норматив ТЗ / ПАЗ] Дрейф нуля:
  - Выявление ложных нулевых значений на расходах пара в стриппинги (F5, F26).
- [Норматив ТЗ / ПАЗ] Регламент мотивированного отказа (Graceful Refusal / Safe Hold):
  - Система ОБЯЗАНА перейти в Safe Hold (delta_u = 0) в следующих случаях:
    1. Критическое устаревание лабораторного анализа LIMS (Delta_tau > 24 часов) при одновременном отказе поточного анализатора серы ПАК (значение NaN).
    2. Выявление аппаратного клампинга или недостоверности критических датчиков КИП.
    3. Конфликт ограничений, при котором ни один кандидат не удовлетворяет барьерам ПАЗ или ГОСТ.

## 5. Экономика, арбитраж и Deadband (ArbitrationNode)

- [Инженерное допущение] Целевая функция чистой маржи:
  Net_Utility = Expected_Margin - Risk_Penalty (руб/ч).
  Выбирается кандидат с максимальной Net_Utility среди допущенных Стадией 1 Hard-Veto.

- [Инженерное допущение] Фильтр зоны нечувствительности (Deadband Filter):
  - Порог экономической эффективности: Net_Utility >= 1000.0 руб/ч. Если маржа ниже порога, режим замораживается (delta_u = 0, DEADBAND_REJECT_LOW_MARGIN).
  - Порог нормы шага: ||delta_u||_2 >= 0.05. Если шаг меньше порога, уставки не меняются (DEADBAND_REJECT_SMALL_STEP).

## 6. Модель компенсации запаздывания лабораторных анализов LIMS (LimsBiasCompensator)

- [Норматив ТЗ / ПАЗ] Запаздывание анализа: фактический лаг ЦЗЛ составляет от 2 до 8 часов. Прямое замыкание редкого анализа LIMS в контур без фильтрации запрещено.
- [Инженерное допущение] Такт дискретизации: dt = 10.0 минут.
- [Инженерное допущение] Ретроспективная ошибка: raw_error = LIMS_value - VAK_historical_at_sampling_time.
- [Инженерное допущение] Экспоненциальное затухание смещения (Bias Decay):
  - Период полураспада доверия к анализу LIMS: T_half = 12.0 часов.
  - Decay_Factor = exp(-decay_lambda * age_minutes), где decay_lambda = ln(2) / (12 * 60).
- [Инженерное допущение] Безударный перенос (Bumpless Transfer):
  - Фильтр первого порядка с постоянной времени tau = 30.0 минут для устранения скачков при вводе анализа.
- [Инженерное допущение] Консервативная оценка (Upper Confidence Bound / UCB 95%):
  - Рост неопределенности: sigma(t) = base_sigma * sqrt(1 + age_hours / 12.0), где base_sigma = 0.3 ppm.
  - Расчетная сера для аудиторов: S_estimated = VAK_current + bias_filtered + 1.96 * sigma(t).
